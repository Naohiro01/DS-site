# デイサービスNao(架空の施設紹介サイト)

介護施設の紹介サイトを想定した、複数ページ構成のWebサイトです。

## 対象ペルソナ

遠方に住む家族(要介護認定を受けた親など)の施設を探している、50代の会社員。

- 仕事の合間、スマホで隙間時間に複数施設を比較検討している
- 「要支援」「要介護」など専門用語にあまり詳しくない
- 施設の雰囲気やスタッフの様子を写真で確認して安心したい

## 課題と設計判断

| 課題 | 対応 |
|---|---|
| スマホでの閲覧が中心 | スマホファーストのレスポンシブ設計 |
| 機種依存文字(絵文字)による表示崩れの懸念 | Material Symbolsのアイコンフォントに統一 |
| 施設の雰囲気が伝わりにくい | 施設外観・内観・スタッフの写真を各ページに配置 |
| 電話をかけたいのはスマホユーザーが中心 | 「電話で応募」ボタンをモバイル幅のみ表示、PCではフォーム誘導 |
| 入力ミスをしたときの体験 | フォームのエラー表示をブラウザ標準の吹き出しから、独自デザインの案内に変更 |

## 使用技術

- HTML / CSS / JavaScript(フレームワークなし)
- Google Fonts(Material Symbols Outlined)

## ページ構成

- トップ / サービス紹介 / 施設紹介 / 1日の流れ / 採用情報 / お問い合わせ
